## Overview

A digital transformation platform for university administration workflows.

## Problem

Paper-heavy processes for approvals, attendance, certificate issuance, and record management created unnecessary manual work.

## Solution

AcadEase 360° centralizes these workflows through a web application backed by APIs and SQL data management.

## Recognition

Runner-up at AURAX 2K26.

## Technology

React, FastAPI, Python, SQL, REST APIs, JSON.
