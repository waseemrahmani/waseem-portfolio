## Overview

A multimodal phishing detection platform combining language, visual, graph, and threat-intelligence signals.

## Approach

The system combines DistilBERT for NLP, YOLO-based visual detection, graph analysis for URLs, and four-source threat-intelligence fusion.

## Results

The project targeted a 96% detection accuracy, sub-50ms response time, lower false positives through 2-of-4 consensus, and production-style containerized deployment with monitoring.

## Technology

Python, FastAPI, React, Docker, Kubernetes, DistilBERT, YOLOv5/v8, GNN, LangChain.
